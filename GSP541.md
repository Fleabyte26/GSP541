# GSP541 - Build a Multi-Agent System with Agent Skills, ADK and A2A: Challenge Lab

Run everything in a Cloud Shell terminal (Open Editor > Terminal > New Terminal works too). Paste one block at a time and read the line under it before moving on.

## Known lab traps/bugs (read first)

1. The checker reads the copies in your agent bucket, not the files in Cloud Shell. If you fix a file after a failed check, upload it again before clicking.
2. REGION and MODEL are different in every lab instance. They are only shown in Task 1, "Configure environment variables" (the export REGION= and export MODEL= lines). A wrong region deploys fine and scores 0.
3. The lab keeps its values in shell variables, which vanish when you open a new terminal. This guide saves them to files in your home folder instead, so any terminal works.
4. Task 5 starts four servers that hold the terminal. Nothing else can be pasted until you press CTRL+C.
5. The first Cloud Run deploy in a fresh project can fail on a build permission that is still propagating. Wait a minute and paste the same block again.
6. The checker lags. If a check fails right after a step, wait 30-60 seconds and click again.
7. The documentation links in the lab show Gemini API keys. Ignore that; this lab runs on Vertex AI through the .env file.

## Task 3. Define the Content Builder agent

First look at the validation script so you know which two headings it checks.

This block rewrites the function so it returns a dictionary with success and message. It reads the two headings from the file itself and keeps a backup in ~/check_format.orig.py.

```bash
cd ~/multi-agent-system-skills-starter
python3 - <<'EOF'
import ast, os, re
p = "agents/content_builder/skills/scripts/check_format.py"
src = open(p).read()
open(os.path.expanduser("~/check_format.orig.py"), "w").write(src)
heads = list(dict.fromkeys(re.findall(r'''["'](#{1,6} ?[^"'\n]+)["']''', src)))
kinds = (ast.FunctionDef, ast.AsyncFunctionDef)
fns = [n for n in ast.walk(ast.parse(src)) if isinstance(n, kinds)]
fn = next((n for n in fns if n.name == "check_format"), fns[0] if fns else None)
args = [a.arg for a in fn.args.args if a.arg not in ("self", "tool_context")] if fn else []
if len(heads) < 2 or not args or fn.body[0].lineno == fn.lineno:
    raise SystemExit("NOT CHANGED - edit this one by hand")
ind = " " * (fn.col_offset + 4)
doc = ast.get_docstring(fn) or "Check that the course module has the required headings."
body = ['"""' + doc.replace('"""', "'''") + '"""',
        "required = " + repr(heads),
        "missing = [h for h in required if h not in " + args[0] + "]",
        "success = len(missing) == 0",
        "if success:",
        '    message = "Format check passed: all required headings are present."',
        "else:",
        '    message = "Format check failed. Missing: " + ", ".join(missing)',
        'return {"success": success, "message": message}']
lines = src.split("\n")
lines[fn.body[0].lineno - 1:fn.end_lineno] = [ind + b for b in body]
new = "\n".join(lines)
ast.parse(new)
open(p, "w").write(new)
print("changed. headings checked:", heads)
EOF
cat agents/content_builder/skills/scripts/check_format.py
```

You should see: changed, with the two headings, then a function that ends in return {"success": success, "message": message}. If it says NOT CHANGED, open the file in the editor and make it return that dictionary yourself: success is True only when both headings are in the text.

## Task 6. Deploy the microservices to Cloud Run

Build the shared environment settings once.

```bash
cd ~/multi-agent-system-skills-starter
printf 'GOOGLE_CLOUD_PROJECT=%s,GOOGLE_CLOUD_LOCATION=global,GOOGLE_GENAI_USE_VERTEXAI=true,MODEL=%s' "`cat ~/project`" "`cat ~/model`" > ~/envvars
cat ~/envvars; echo; cat ~/region
```

You should see one line with your project and model, then your region.

Deploy the three specialists (about 3 minutes each; they run one after another).

```bash
cd ~/multi-agent-system-skills-starter
gcloud run deploy researcher --source agents/researcher/ --region "`cat ~/region`" --allow-unauthenticated --memory 512Mi --quiet --set-env-vars "`cat ~/envvars`" && \
gcloud run deploy judge --source agents/judge/ --region "`cat ~/region`" --allow-unauthenticated --memory 512Mi --quiet --set-env-vars "`cat ~/envvars`" && \
gcloud run deploy content-builder --source agents/content_builder/ --region "`cat ~/region`" --allow-unauthenticated --memory 512Mi --quiet --set-env-vars "`cat ~/envvars`"
gcloud run services list --region "`cat ~/region`" --format="value(metadata.name)"
```

You should see: content-builder, judge, researcher. If one failed, paste the block again.

Save the three URLs and deploy the orchestrator pointing at their agent cards.

```bash
cd ~/multi-agent-system-skills-starter
gcloud run services describe researcher --region "`cat ~/region`" --format='value(status.url)' > ~/researcher_url
gcloud run services describe judge --region "`cat ~/region`" --format='value(status.url)' > ~/judge_url
gcloud run services describe content-builder --region "`cat ~/region`" --format='value(status.url)' > ~/builder_url
printf 'RESEARCHER_AGENT_CARD_URL=%s/a2a/agent/.well-known/agent-card.json,JUDGE_AGENT_CARD_URL=%s/a2a/agent/.well-known/agent-card.json,CONTENT_BUILDER_AGENT_CARD_URL=%s/a2a/agent/.well-known/agent-card.json,%s' "`cat ~/researcher_url`" "`cat ~/judge_url`" "`cat ~/builder_url`" "`cat ~/envvars`" > ~/orchvars
cat ~/orchvars; echo
gcloud run deploy orchestrator --source agents/orchestrator/ --region "`cat ~/region`" --allow-unauthenticated --memory 512Mi --quiet --set-env-vars "`cat ~/orchvars`"
```

Before the deploy starts you should see one long line with three https URLs ending in agent-card.json. If any URL is empty, that service is not deployed yet.

Deploy the frontend.

```bash
cd ~/multi-agent-system-skills-starter
gcloud run services describe orchestrator --region "`cat ~/region`" --format='value(status.url)' > ~/orch_url
gcloud run deploy course-creator --source app --region "`cat ~/region`" --allow-unauthenticated --memory 512Mi --quiet --set-env-vars "AGENT_SERVER_URL=`cat ~/orch_url`,GOOGLE_CLOUD_PROJECT=`cat ~/project`"
gcloud run services describe course-creator --region "`cat ~/region`" --format='value(status.url)'
```

You should see the course-creator URL on the last line.
